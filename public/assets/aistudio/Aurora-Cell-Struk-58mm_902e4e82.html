Instal di HP Android (Cetak Fisik)

Agar tombol Cetak via RawBT, Cetak Sistem (58mm), dan Bluetooth ESC/POS berjalan penuh tanpa diblokir jendela pratinjau, unduh aplikasi ini ke HP Android Anda:

  1. Buka di Chrome Android: Buka aplikasi File Saya / Download, ketuk Aurora-Cell-Struk-58mm.html dan pilih buka dengan Google Chrome.
  2. Pasang ke Layar Utama: Di Chrome, ketuk menu titik tiga (⋮) di pojok kanan atas → pilih Tambahkan ke layar utama agar muncul ikon seperti aplikasi biasa.
  3. Cetak ke Printer Thermal 58mm: Pasangkan printer thermal Bluetooth di pengaturan HP, pasang aplikasi RawBT (dari Play Store), lalu gunakan tombol Cetak via RawBT (Android) atau Cetak Sistem (58mm).
  4. Opsional Web Bluetooth Langsung: Web Bluetooth memerlukan koneksi localhost atau https. Jika ingin mencetak langsung tanpa RawBT, jalankan di Termux: cd ~/storage/downloads && python -m http.server 8080 lalu buka http://localhost:8080/Aurora-Cell-Struk-58mm.html.
